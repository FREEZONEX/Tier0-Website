# 发版

1. 合并前运行 `npm run check`，用浏览器验证受影响页面及真实交互。
2. 从干净提交运行 `npm run package -- --version YYYY.MM.DD.N`，每次版本号唯一。
3. 在 GitHub Releases 创建对应 tag，附件上传 dist 中的站点 ZIP、SHA256 和 commit 记录。不要把 ZIP 提交到代码仓库。
4. 由负责人按运维提供的部署流程执行服务器 dry-run；校验通过后备份并发布。凭据通过安全渠道提供，不放本仓库。
5. 公网验收：首页及实际页面内容、导航、6个PDF下载按钮、本地PDF分段请求、备案号、MES/WMS交互。目录路径末尾 `/` 和无尾斜杠入口都要检查。
6. 记录版本、commit、SHA256、校验结果和回滚位置。失败按实际发布流程停下，不绕过门禁。

地区引导资源 `scripts/geo-guidance.v*.js` 和 `styles/geo-guidance.v*.css` 也供国际官网 Framer 使用。更新时发布新的文件名，保留两站仍在使用的版本。回滚整站时保留 Framer 仍引用的 JS 和 CSS 并回读正式 URL。若无法保留，先在 Framer 撤下引用或切回可用版本，确认发布生效后再回滚国内站。
